# 05. UI 규칙 (사용자가 확정한 것)

여러 차례 수정을 거쳐 정한 최종 상태다. 본개발에서도 그대로 따른다.

## 레이아웃
- 전체 배경은 흰색(#fff)이다. 콘텐츠 **최대 폭은 1024px**이고 가운데 정렬한다.
- 바깥 wrap에는 테두리·여백·패딩을 두지 않는다. 하단 메뉴 위에 빈 간격을 두지 않는다.
- 모바일 기준은 390×780이다. 좌우 여백은 16px(700px 이상에서는 24px)이다. 가로 스크롤이 생기면 안 된다.
- 섹션은 회색 띠(8px)로 나눈다(당근마켓식 납작한 섹션).
- 아이패드·모바일 반응형이다. 작은 폰(≤380px)에서는 글자와 버튼을 조금 줄인다.
- 슬라이드 카드는 **모바일 한 화면에 다 보여야** 한다. 스크롤이 생기지 않게 문장을 줄 수 제한한다.

## 헤더 · 탭
- **공부 화면**
  - 1줄: 과목 드롭다운(굵은 제목 + ⌄)과 오른쪽 아이콘(검색·알림·전체보기).
  - 2줄: 탭2 알약.
  - 3줄: 과목 안 갈래 **라인 탭**. 선택된 탭은 글자가 진해지고 아래에 2.5px 검정 선이 생긴다.
- **놀이터**(홈·게임·랭킹·마이): 흰 헤더에 아래 경계선이 있다. 홈에는 알약을 두지 않는다.
- **알약 탭은 테두리 없이 배경색으로만** 표시한다. 선택은 #1E2421 배경에 흰 글자, 기본은 #F1F3F6 배경이다.
- 서브페이지에서는 상단 헤더를 숨긴다.
- 오른쪽 아이콘 여백은 왼쪽 여백과 같게 맞춘다.
- 숫자 배지는 #FF4F1F 배경, 흰 글자, 둥근 모양이다.

## 색
- 기본 글자 #1E2421, 보조 글자 #5B6169, 흐린 글자 #8A9099, 선 #E1E4EA, 연회색 면 #F1F3F6 / #F6F7F9.
- 주요 행동 버튼은 검정(#1E2421)이다. 과목 주색은 강조와 진행 표시에만 쓴다.

## 글꼴
- 본문은 Noto Sans KR(400/500/700/900)이다.
- 한자와 천자문은 Noto Serif KR(500/700)이다.

## 아이콘
- **Lucide만** 쓴다(프로토타입은 lucide-static 0.460.0 인라인 SVG).
- 아이콘과 텍스트는 **세로 가운데 정렬**한다. 예: 설정 줄의 연필 아이콘 16px, `vertical-align:-3px`.
- 닫기 버튼은 Lucide `x`를 쓴다. 모달 하단 버튼은 한 줄에 둔다.

## 문구
- 해요체로 짧게 쓴다. 학생이 읽는 문구에는 기술 용어를 쓰지 않는다.
- 정확한 표현을 쓴다. 예: "모두 끝내면 …" 대신 "**오늘 할 일을 모두 끝내면** 꾸미기와 게임(스피드·대결)이 열려요".
- 피드백 문구 예: "정답! 다음 문제로 넘어가요", "정답은 ○ · 3문제 뒤 다시 나와요", "오답 졸업!".

## 상호작용
- 맞힘·틀림 효과음이 있고, 마이 설정에서 끌 수 있다.
- 영단어는 카드나 단어를 누르면 발음을 읽어 준다.
- 슬라이드는 스와이프와 키보드 ←/→로 넘기고, Esc로 닫는다.
- 지우기처럼 되돌릴 수 없는 행동은 확인 대화상자를 거치거나 두 번 눌러야 실행된다.
