# 02. 작업 내역과 결정 (2026년 10월)

프로토타입은 Claude 작품(artifact) 하나로 계속 고쳐 왔다. 현재 Version 62이고, 배포용 파일은 `prototype/dist/index.html`이다.
아래는 단계별로 무엇을 만들고 어떤 결정을 내렸는지 정리한 것이다. 날짜는 대략적이다.

## 1단계 — 연산 앱 「셈하루」
- 경쟁사 분석 → 기획서 → 프로토타입 순으로 진행했다.
- 조안호 국민연산을 참고해 규칙을 정했다. 개념을 읽어야 문제가 열리고, 연속 10문제를 맞히면 통과한다. 오답은 1·3·5일 뒤 다시 나오고, 통과한 단계는 3~5일마다 복습한다.
- 단계를 34개에서 87개로 늘렸다. 받아올림이 갑자기 어려워지는 구간을 없애려고 쉬운 것부터 어려운 것까지 차례로 문제은행을 만들었다.
- 단계 안에서도 난이도를 조절한다. 연속으로 맞히면 오르고, 틀리면 내려간다.
- 문제 형식을 다양하게 했다: 빈칸, 세로셈, 객관식, OX, 크기 비교, 문장제. 숫자만 바뀌는 반복이 지루하다는 지적을 반영했다.
- 세 자리 수 연산은 필요 없다고 판단했다. 기초를 반복해 튼튼하게 하는 방향으로 정했다.
- 색은 노랑+검정 → 당근색 → 민트를 거쳐, 지금은 과목별 주색 체계로 정리했다. UI 문법은 당근마켓을 참고했다(흰 앱바, 회색 띠 섹션). 아이콘은 Lucide만 쓴다.

## 2단계 — 과목 확장 → 「하루공부」
- **한자**: 부수부터 한국어문회 8급~1급까지 3,500자로 구성했다. 획순 따라쓰기, 생성 원리(본뜬 모양), 관련 한자어를 넣었고, 학교 필수/급수별 두 갈래를 만들었다.
- **영단어**: 초→중→고 3,000단어로 구성했다. 발음 듣기, 예문, 펜으로 쓰기를 넣었다.
- **역사**: 국사·세계사, 초→고. 고등까지 튼튼하게 하는 것이 목적이다.
- **국어**: 자주 틀리는 맞춤법부터 시작한다(빈도 분석). 어휘와 수업 갈래가 있다.
- **타자**: 한글·영문 자리 연습, 낱말, 짧은 글, 산성비 게임을 만들었다.
- **과학**: 물리·화학·생명·지구, 초3→고2(2022 개정 교육과정)로 구성했다. 처음 만든 뒤 "빠진 게 많다"는 피드백을 받아 기초부터 다시 채웠다. 229단원이며, 단원마다 앞 단원(pre) 연결과 핵심 원리를 넣었다.
- 과목마다 주색을 따로 쓰기로 했다.

## 3단계 — 동기부여(놀이터)
- 캐릭터와 아바타 꾸미기를 넣었다(약 660개 아이템). 세이클럽·로블록스식 레이어 꾸미기를 참고했다.
- 뽑기, 아이템 거래, 현금 결제는 넣지 않기로 했다. 확률형 아이템 규제와 아동 안전 때문이다.
- 캐시는 맞힌 수 − 틀린 수로 계산한다. XP 등급과 랭킹을 넣었다.
- 오늘 할 일(과목별 분량, 보호자가 정함)을 끝내야 꾸미기와 게임이 열린다. 하루 게임 횟수 제한, 밤 9시 잠금(선택), 밀린 공부 갚기, 정해 둔 시간 알림도 넣었다.
- 게임으로 스피드 게임, 대결방(방장 개설·초대, 정해진 문구 채팅), 종합 대결(타자를 뺀 과목 섞기)을 만들었다. 산성비 게임은 타/분 속도를 표시하고 타자 속도 랭킹을 둔다. 비공개 방은 6자리 코드로 들어간다.
- 지금 대결방 상대는 가상 참가자다. 실제 버전에서는 Supabase Realtime으로 바꾼다.

## 4단계 — 앱 구조 정리 (셸)
- 하단 공통 메뉴는 홈·공부·게임·랭킹·마이다. 공부에는 남은 문제 수, 랭킹에는 내 순위 숫자 배지를 단다.
- 공부 화면 헤더는 "과목 ⌄" 드롭다운, 검색·알림·전체보기 아이콘, 그 아래 탭2(과목학습·오답노트·학습결과) 알약으로 구성했다.
- 과목 안 갈래 탭은 라인 탭이다. 서브페이지(뒤로가기 화면)에서는 헤더를 숨긴다.
- 꾸미기는 마이 안으로 옮겼다(내 정보·통계·꾸미기·설정). 이름 수정도 마이에서 한다.
- 로그인, 회원가입, 자녀 선택, 로그아웃, 계정 탈퇴 화면을 만들었다(확인 대화상자 포함).
- 맞힘·틀림 효과음(켜고 끄기)을 넣었다. 영단어 카드를 누르면 발음을 읽어 준다.
- 오답이나 복습으로 다시 풀 때 정답 위치가 지난번과 달라지게 했다.

## 5단계 — 천자문 · 슬라이드 · 단어장 · 검색 (최근)
- **천자문 탭**(한자 3번째 갈래): 5부, 250구절, 1,000자다. 구절 뜻·다음 구절·빈칸 한자·구절 읽기 문제가 있다. 읽기는 두음법칙을 따른다(露 '이슬 로' → 구절 '노결위상').
- **슬라이드 학습** (한자·영단어·국어·과학·역사):
  - 사용자 의도는 문제 풀이가 아니라 **크게 보고 듣고 이해하는 카드**다.
  - 카드는 모바일 한 화면에 들어간다. 단어를 크게 쓰고, 아래에 뜻·어원·쪼개기·관련어·예문을 둔다. 한자 카드에는 본뜬 모양 그림을 넣었다.
  - 받아쓰기는 **소리만 불러 주고** 학생이 직접 쓴다. 입력칸과 채점은 없고, 끝나면 정답 목록이 나온다.
  - 속도는 0.5×~4×다. 자동 넘김 중에는 남은 시간을 표시한다(재생 버튼 링 + "다음 카드까지 N초").
  - 목소리는 신뢰감 있게: 기기에서 가장 자연스러운 목소리를 자동으로 고르고, 설정에서 직접 고를 수도 있다.
- **영단어 어원 3,000개** 작성: 어원, 단어 쪼개기, 같은 뿌리, 비슷한 말·반대말, 표현. 확실하지 않으면 그렇다고 썼다.
- **나만의 단어장**: 카드의 ☆로 담고, 카테고리별로 정리해 언제든 슬라이드·받아쓰기로 복습한다. 과목·학생별로 저장된다.
- **통합 검색**: 헤더 🔍에서 11,051개 항목을 찾는다. 초성 검색과 범위 버튼이 있고, 결과를 누르면 상세 보기와 '공부하러 가기'가 나온다.
- 기획서 2건을 작성했다: 슬라이드 기능 기획서(경쟁사 분석), 수익성 조사.

## 정리해 둔 사용자 선호
- 수정 지시는 짧고 반복적이다. "원복"은 직전 상태로 되돌리라는 뜻이다.
- 헤더·탭 스타일은 여러 번 바뀌었고 최종은 `05_ui_guide.md`에 있다.
- 퍼블리싱을 요청하면 순수 마크업 + 간단한 스크립트만 준다. 개발 소스는 넣지 않는다.
- 앱 이름: 「하루공부」를 쓰고 있지만, '하루'가 흔한 이름이라 바꿀지 고민 중이다.
