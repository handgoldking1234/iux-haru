# 07. 콘텐츠 데이터

`prototype/build/`(빌드 입력)과 `prototype/data/`(원본·작성 규칙)에 들어 있다. 본개발에서는 이 JSON을 DB로 옮기는 것이 첫 작업이다.

## 파일과 형식

### 한자 `build/data.json` (+ 천자문 → 빌드 때 `data_hj.json`으로 합침)
```
LV: ["8급","7급Ⅱ",…,"1급"]                       13개 급수
CH: [[한자, 훈, 음, 다른음, 급수idx, 부수, 획수], …] 3,500자
ST: [[급수idx, 단원번호, "一二三…"], …]             352단원
WD: {한자: "國家국가 家族가족 …"}                   관련 한자어(앞 2자=한자, 뒤=읽기)
OR: {한자: "F|뜻부분|소리부분" | "H|구성" | "R|부수|나머지" | "S"}  생성 원리
CP: {부분: "훈 음"}                                 부품(부수 등) 이름
BASIC: "家價…"                                      교육용 기초 한자 1,800자
CJM: (data/cjm/cjm.json) {intro, parts:[{name,title,from,to}×5], ph:[{p:"天地玄黃", r:"천지현황", h:["하늘 천",…4], m:"뜻", x:"풀이"}×250]}
```
- 본뜬 모양 그림은 `build/pics.js`(SVG path, 직접 그림), 획순은 `build/strokes.js`(8급~5급 + 부수)에 있다.
- 천자문 읽기 `r`은 두음법칙을 적용했다(34자). `h`는 원래 소리다.

### 영단어 `build/eng.json` (+ 어원 `data/eng_ety/out1~6.json`)
```
LV: ["초등","중등","고등"]
W:  [[단어, 학교급idx, 품사, 뜻, 예문, 예문해석, 주제, 다른형태, 파생어, 발음기호], …]  3,000개
ST: [[학교급idx, 단원번호, 주제, "man|people|…", 필수핵심여부], …]
ETY: {단어: {et:"어원", pt:"un(아닌)+happy", fam:[[단어,뜻]], syn:[[…]], ant:[[…]], ph:[[표현,뜻]]}}
```

### 국어·과학·역사 `build/kor.json`, `build/hist.json`, 과학(`data/sci/v2/*`를 빌드 때 합쳐 `sci.json`)
```
{ 갈래키: { units: [ {
    lv: 0|1|2, n: 단원번호, title, tag?, era(부제·시기), sum(개념 정리),
    pr?: [{h:원리 제목, b:설명}],   (과학)
    pre?: "앞 단원 제목",            (과학)
    items: [{t:용어, d:설명, k:분류, y:연도|null, yl:연도표시, ex?:예문, w?:[틀린 표기]}] ×10,
    mc?:   [{q:문제, p:지문, c:[보기4], a:정답idx, e:해설, lv:1~3}]
} ] } }
갈래: 국어 vc(어휘)·kr(수업)·mix / 과학 phy·chem·bio·earth (통합 mix는 실행 중 생성) / 역사 ko·wo
hist.json TL: [[연도, 갈래, 사건, 학교급, 표시, 비고], …]   연표
```
- 작성 규칙: `data/kor/SPEC.md`, `data/kor/MC_SPEC.md`, `data/hist/SPEC.md`, `data/sci/v2/SPEC.md`.
- 과학은 영역·학교급별 파일 12개 + 보강 파일 `add_*.json`이다. 보강 단원은 `after`(앞 단원 제목, `^`는 맨 앞) 자리에 끼워 넣는다.

### 타자 `build/typ.json`
`koW`(한글 낱말 508) · `koS`(문장 302) · `enW`(영문 낱말 752) · `enS`(문장 794).
