# 역사 학습 데이터 작성 규칙 (한국 학생용)

출력: 지정된 경로에 UTF-8 JSON 파일 하나. 형식:
{"track":"국사"|"세계사","level":"초등"|"중등"|"고등","units":[UNIT,...]}

UNIT = {
 "title": 단원 제목(주어진 목록 그대로),
 "era": 시기 표기 (예: "기원전 70만 년 ~ 기원전 108년", "918 ~ 1392"),
 "sum": 단원 개념 정리 3~5문장. 흐름이 보이게(원인→전개→결과). 해당 학교급 눈높이의 쉬운 한국어.
 "items": ITEM 정확히 10개 (단원의 핵심 용어·인물·사건·제도·문화유산)
}
ITEM = {
 "t": 용어 (짧게: "고조선", "세종", "훈민정음 창제", "대동법"),
 "d": 설명 한 문장(25~60자). **d 안에 t의 글자(용어 자체)를 쓰지 말 것** — 설명을 보고 용어를 맞히는 문제로 쓰임. 해당 단원 안에서 다른 항목과 헷갈리지 않게 구별되는 핵심 특징을 담기.
 "y": 대표 연도 정수(기원전은 음수, 예: -2333) — 특정 연도가 교과서에서 통용될 때만. 인물은 대표 업적 연도나 즉위 연도. 불확실하거나 기간 개념이면 null.
 "yl": 연도/시기 표시 문자열 (예: "기원전 2333년(전승)", "1443년", "5세기", "조선 후기"). y가 있으면 반드시 일치.
 "k": 종류 — 인물 | 사건 | 나라·왕조 | 제도·정책 | 문화유산 | 개념 중 하나
}

정확성 최우선: 한국 검정 교과서(초등 사회 5-2·6-1, 중학 역사, 고등 한국사/세계사)에서 통용되는 사실·연도·용어만. 논쟁적이거나 불확실한 연도는 y=null로 두고 yl에 시기만. 전승 연도(단군 기원전 2333년 등)는 "(전승)" 표시.
표기: 한국 교과서 표기(예: 을사늑약, 6·25 전쟁, 5·18 민주화 운동, 진시황, 나폴레옹). 현대사는 1990년대 정도까지, 정치적 평가 없이 중립적 사실만.
학교급: 초등은 쉬운 말·대표 사실 위주, 고등은 제도·정책·세부 사건까지.
같은 파일 안에서 같은 t가 두 번 나오지 않게.
완성 후 python으로 JSON 파싱, 단원 수, 각 단원 items=10, d에 t 문자열 미포함, y/yl 일치를 검증하고 고칠 것. 마지막에 "done U units"만 보고.
