# 국어 학습 데이터 작성 규칙 (한국 학생용)

출력: 지정된 경로에 UTF-8 JSON 파일 하나:
{"level":"초등"|"중등"|"고등","units":[UNIT,...]}

UNIT = {
 "title": 단원 제목(주어진 목록 그대로),
 "era": 단원 부제 한 줄(예: "되/돼, 안/않, 로서/로써"),
 "sum": 단원 개념 설명 3~5문장. 규칙·원리를 학교급 눈높이로 쉽게. 예를 들어 설명.
 "items": ITEM 정확히 10개
}
ITEM = {
 "t": 정답(용어·바른 표기·속담·사자성어 등). 짧게.
 "d": 설명 한 문장(20~70자). **d 안에 t를 그대로 쓰지 말 것**(설명 보고 t를 고르는 문제로 씀). 같은 단원 다른 항목과 헷갈리지 않는 핵심 특징.
 "k": 맞춤법 | 띄어쓰기 | 어휘 | 속담 | 사자성어 | 관용어 | 문법 | 문학 | 개념 중 하나
 "w": (맞춤법·띄어쓰기·표준어 항목에만) t와 헷갈리는 틀린 표기 2~3개 배열. 예: t "어떡해", w ["어떻해","어떻케"]. 모두 실제로 틀린 표기여야 함. 그 외 항목은 생략.
 "ex": 쓰임 예문 한 문장(선택, 15~50자). 맞춤법 항목은 바른 표기를 쓴 예문. 사자성어는 한자 표기를 괄호로 넣어도 됨(예: "일석이조(一石二鳥)로 …").
 "y": null, "yl": "" (항상 이렇게 둘 것)
}

정확성 최우선: 국립국어원 표준국어대사전·한글 맞춤법·표준어 규정, 한국 국어 교과서(초등 국어, 중학 국어, 고등 국어·언어와 매체)에서 통용되는 내용만. 문법 용어는 학교 문법 용어.
맞춤법 항목은 실제 아이들이 자주 틀리는 것 위주. 띄어쓰기 항목의 t·w는 짧은 구/문장으로.
같은 파일 안에서 같은 t 중복 금지.
완성 후 python으로 검증: JSON 파싱, 단원 수, 각 단원 items=10, d에 t 미포함, w가 있으면 t와 다르고 2~3개. 고칠 것. 마지막에 "done U units"만 보고.
