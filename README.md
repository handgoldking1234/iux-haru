# 하루공부

초등~고등 통합 학습 앱(연산·한자·영단어·국어·과학·역사·타자 + 보상·게임).

- `CLAUDE.md` — Claude Code 작업 안내(먼저 읽기)
- `docs/` — 개요·작업 내역·규칙·화면·UI·구조·데이터·로드맵
- `prototype/dist/index.html` — 완성된 HTML 프로토타입(브라우저로 열기)
- `prototype/build/` — 프로토타입 소스와 빌드 스크립트(`npm install && python3 build.py`)
- `prototype/data/` — 콘텐츠 원본(천자문·영단어 어원·과학·국어·역사)과 작성 규칙
