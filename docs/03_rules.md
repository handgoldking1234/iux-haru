# 03. 학습·보상 규칙 정의서 (개발 기준)

이 문서의 숫자는 사용자가 확정한 값이다. 바꾸려면 먼저 사용자에게 묻는다.
괄호 안은 프로토타입에서 그 규칙을 구현한 곳이다.

## 1. 공통 학습 흐름 (한자·영단어·국어·과학·역사)

엔진은 `app.js`(한자)와 `eng.js`·`kor.js`·`sci.js`·`hist.js`가 같은 구조를 쓴다.

```
GOAL=10, SET=20, CARD_GAP=[1,3,5], REV_GAP=[3,5], EXAM_N=20, EXAM_PASS=0.8, REV_Q=4
```

### 1-1. 학습 길
- 과목마다 단원을 차례로 연다.
  - 예(한자 급수별): 부수 6단원 → 부수 확인 평가 → 8급 단원들 → 8급 승급 평가 → 7급Ⅱ … → 1급.
  - 예(영단어): 초등 → 중등 → 고등. 학교급마다 끝에 승급 평가가 있다.
- **새 단원 첫 진입**: 소개 카드(뜻·음·생성 원리·관련 단어·예문, 과학은 핵심 원리)를 끝까지 넘겨야 문제가 열린다.
  - 한자 8급~5급은 '쓰기 문제 넣기'를 켜면 획순대로 따라 써야 다음 카드로 넘어간다.
- 개념·소개는 언제든 다시 볼 수 있다: 문제 화면 ?, 오답 직후, 단원 목록, 오답노트, 학습결과.

### 1-2. 단원 안 진행
- **난이도 위치** `bp`(0~9)
  - 맞히면 +1, 연속 2개 이상 맞힌 중이면 +2.
  - 틀리면 −2.
  - 구간: 0~2 쉬움, 3~5 보통, 6~9 어려움. 난이도에 따라 문제 유형이 바뀐다(예: 영단어 쉬움 '뜻 고르기' → 어려움 '예문 빈칸·철자·듣기').
- **통과**: 어려움 구간(bp≥6)에서 **연속 10문제 정답** → 단원 통과 → 다음 단원은 소개부터 시작한다.
- **틀렸을 때**
  - 난이도가 내려간다.
  - 같은 문제를 **3문제 뒤 다시** 낸다. 이때 보기 순서를 섞어 정답 위치가 직전과 다르게 한다.
  - 오답노트에 담는다.
- **틀림 상한**: 한 단원에서 아래 개수만큼 틀리면 그 단원을 **처음(소개)부터 다시** 한다.

| 학교급/급수 | 상한 |
| --- | --- |
| 초등, 부수, 8급~7급 | 5 |
| 중등, 6급Ⅱ~5급 | 6 |
| 고등, 4급Ⅱ~3급 | 7 |
| 2급·1급 | 8 |

### 1-3. 오답노트 (간격 반복)
- 틀린 문제는 카드가 되어 **1일 → 3일 → 5일** 뒤 다시 나온다.
- 세 번 연속 맞히면 **졸업**한다. 중간에 틀리면 1일로 돌아간다.
- 같은 글자·같은 유형을 또 틀리면 새 카드를 만들지 않고, 기존 카드를 1일로 되돌리고 틀린 횟수만 더한다.

### 1-4. 통과 단원 복습
- 통과한 단원은 **3단원 뒤, 5단원 뒤** 두 번 복습한다(진도 간격 반복). 복습 1회는 4문제(`REV_Q`)다.
- 두 번 다 끝내면 '완성'이다. 복습할 단원이 있으면 새 진도보다 먼저 나온다.

### 1-5. 승급 평가
- 학교급·급수 끝에 20문제를 낸다. 16개(80%) 이상 맞히면 다음으로 넘어간다.
- 5개를 틀리면 그 자리에서 끝난다. 틀린 문제는 오답노트에 담긴다.

### 1-6. 오늘 학습 구성 (한 세트 20문제)
- 순서: 오답 카드(최대 8) → 복습 단원(최대 3단원 × 4문제) → 새 진도(나머지, 최소 4).
- 버튼: 시작(전체), 오답만, 진도만.

## 2. 연산 (math.html)
- 기초(초1 덧셈)부터 시작한다. 새 단계는 개념 설명을 끝까지 넘겨야 문제가 열린다.
- 단계마다 연속 10문제를 맞히면 다음 단계로 간다.
- 틀린 문제는 같은 세트에서 3문제 뒤 다시 나오고, 오답노트에 담긴다(1·3·5일, 3번 연속 맞히면 졸업).
- 통과한 단계는 3~5일마다 복습한다. 다 맞으면 5일 뒤, 틀리면 3일 뒤다.
- 오늘 학습 20문제 = 오답 최대 10 → 단계 복습 최대 6 → 새 진도.
- 틀림 상한(그 단계를 개념부터 다시): 초1·2는 5, 초3·4는 6, 초5·6은 7, 그 외 8.
- 세 자리 수 연산은 넣지 않는다.

## 3. 한자 갈래
- **학교 필수**: 초등(8급~6급) → 중등(5급Ⅱ~4급 중 교육용 기초 한자) → 고등(3급Ⅱ~1급 중 교육용 기초 한자).
- **급수별**: 부수 60자 → 8급~1급(한국어문회).
- **천자문**: 5부, 50구절씩, 4구절이 1단원이다. 단원 안에서 구절 문제가 45% 확률로 섞인다.
  - 구절 문제 유형: 구절 뜻(pm), 다음 구절(pn), 빈칸 한자(pb), 구절 읽기(pr).
- 각 갈래는 진도를 따로 저장한다.

## 4. 타자
- **자리 연습**: 기본 자리 → 윗줄 → 아랫줄 → Shift → 전체. 다음에 칠 키와 손가락을 화면 자판에 표시한다.
  - 한 판은 30타다. 5개 틀리면 처음부터다. 통과하면 다음 단계가 열린다.
- **낱말 연습**은 10개, **짧은 글**은 5문장이다. 다 맞게 치면 자동으로 넘어가고, 타수(타/분)와 정확도를 보여 준다.
- **산성비 게임**: 떨어지는 낱말을 쳐서 없앤다. 5개를 놓치면 끝나고, 10개마다 빨라진다. 타/분을 표시하고 타자 속도 랭킹에 올린다.

## 5. 보상 (hgs.js — 셸과 놀이터가 함께 쓰는 저장소)

| 항목 | 규칙 |
| --- | --- |
| 캐시 | 정답 +1, 오답 −1. 0 밑으로 내려가지 않음. **공부 캐시 하루 최대 150** |
| 보너스 | 5문제 연속 정답 +3 · 오답 졸업 +5 · 단원 통과 +20 · 오늘 할 일 완료 +20 · 밀린 하루치 다 갚으면 +5 |
| XP·등급 | 맞힌 문제 수로만 쌓이고 내려가지 않음. 씨앗 0 → 새싹 150 → 잎새 400 → 꽃 800 → 나무 1,300 → 숲 2,000 → 별 3,000 |
| 오늘 할 일 | 과목별로 맞힐 문제 수를 보호자가 정함. 기본값: 연산 20, 한자 10, 영단어 10, 국어 10, 역사·과학·타자 0 |
| 잠금 | 오늘 할 일을 **모두 끝내야** 꾸미기·게임(스피드·대결)이 열림 |
| 밀린 공부 | 지난 7일 동안 못 끝낸 할 일이 쌓이고, 오늘 할 일을 넘긴 정답으로 오래된 것부터 갚음. 보호자 설정 '밀린 공부도 끝내야 열기'(기본 켬) |
| 게임 횟수 | 하루 3판(보호자가 1/3/5 중 선택). 할 일을 끝낸 뒤 20문제를 더 맞히면 +1판 |
| 게임 캐시 | 하루 최대 30 |
| 밤 잠금 | 밤 9시 이후 게임 잠금(선택) |
| 알림 | 정해 둔 시간에 앱 안 알림 + 브라우저 알림(허용 시). 기본 16:00 '공부할 시간', 20:00 '오늘 할 일 확인' |
| 금지 | 캐시를 현금으로 사고팔기, 뽑기, 아이템 거래 |

과목 화면은 `postMessage({hg:'ok'|'no'|'pass'|'grad', s:과목키})`로 셸에 결과를 알리고, 셸이 `HGS.event()`로 보상을 계산한다.

## 6. 게임 · 대결방
- **스피드 게임**: 과목별 문제를 빨리 푸는 게임이다.
- **종합 대결**: 타자를 뺀 과목을 골고루 섞는다.
- **대결방**
  - 방장이 방을 만들고 초대한다. 공개 방과 비공개 방(6자리 코드)이 있다.
  - 채팅은 정해진 문구와 이모지만 쓸 수 있고, 닉네임만 보인다.
  - 프로토타입의 상대는 가상 참가자다. 실서비스에서는 실시간 서버로 바꾼다.
- 게임 점수도 맞힌 수 − 틀린 수로 계산한다.

## 7. 슬라이드 · 받아쓰기 · 단어장 (slide.js)
- **범위**: 오늘 할 일(오답 + 지금 단원) / 오답만 / 지금 단원 / 단어장 카테고리. 한 번에 최대 40장.
- **순서**: 차례대로 / 무작위 / 오답 먼저.
- **보기 모드**
  - 큰 글자, 뜻, 설명 카드를 보여 준다.
  - 처음에 앞면과 뜻을 한 번 읽어 준다.
  - 자동 넘김을 켜면 카드마다 정한 횟수(1~3)만큼 읽은 뒤, 3·4·6·10초 기다렸다 넘어간다.
- **받아쓰기 모드**
  - 소리만 불러 준다. 영어는 단어, 한자는 훈음, 천자문은 구절 읽기, 국어·과학·역사는 용어를 부른다.
  - 학생은 공책에 쓴다. 채점·캐시는 없다.
  - 카드마다 '정답 보기'가 있고, 끝나면 정답 목록이 나온다. 쓰는 시간은 4·6·8·12초다.
- **자동 넘김 타이머**: 기다리는 동안 재생 버튼 링과 "다음 카드까지 N초"(받아쓰기는 "쓰는 시간 N초")를 표시한다.
- **속도**: 0.5 · 0.75 · 보통(0.95) · 1.25 · 1.5 · 2 · 3 · 4배.
- **목소리**: 자연스러운 목소리(Natural·Neural·Online·Google·Siri 계열)를 자동으로 고르고, 설정에서 언어별로 바꿀 수 있다.
- **슬라이드 보상**: 지금은 없다. 기획서 제안: 덱 완주 +1, 일일 상한 5.
- **단어장**
  - 카드 ☆로 담는다. 여러 카테고리에 담을 수 있다.
  - 카테고리를 만들고, 이름을 바꾸고, 지울 수 있다(지울 때는 두 번 확인).
  - 과목·학생별로 저장된다.

## 8. 검색 (search.js)
- **대상**: 영단어, 한자, 천자문, 국어·과학·역사 용어와 단원. 연산·타자는 제외한다.
- **점수**: 제목 일치 100 > 제목 시작 80 > 제목 포함 62 > 뜻 일치 58 > 검색어 키워드 50 > 뜻 포함 44 > 설명 포함 18. 단원에는 +6을 더한다. 결과는 최대 120개다.
- **초성 검색**: 검색어가 자음만이면 제목의 초성과 맞춘다.
- 최근 검색어는 10개까지 저장한다.

## 9. 계정 · 안전
- 계정은 보호자 이메일로 만든다. 자녀는 닉네임과 학년만 받는다(만 14세 미만 법정대리인 동의).
- 계정 탈퇴는 확인 대화상자를 거친다.
- 결제는 보호자 화면에서만 한다(향후).
