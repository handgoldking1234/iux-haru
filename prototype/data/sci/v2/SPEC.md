# 하루공부 과학 문제은행 v2 — 작성 규칙 (모든 작성자 공통)

목표: 2022 개정 교육과정(초3~6 → 중1~3 → 고1 통합과학 → 고2 물리학·화학·생명과학·지구과학 일반선택)의 기초 개념을 **하나도 빠뜨리지 않고**, 앞 단원을 알면 다음 단원을 이해할 수 있도록 **차근차근** 쌓이게 만든다. 단원 하나는 작은 주제 하나(한 차시~두 차시 분량).

## 출력 형식 (UTF-8 JSON, 주석 없음)
{"units":[UNIT, ...]}  ← 배정받은 단원 목록 순서 그대로

UNIT = {
 "lv": 0|1|2,            // 0 초등, 1 중등, 2 고등
 "title": "배정 목록의 단원 이름 그대로",
 "tag": "물리"|"화학"|"생명"|"지구",
 "era": "학년 · 교과 단원명 (예: 초3 · 자석의 이용)",
 "pre": "이 단원 전에 알면 좋은 것 한 줄 (앞 단원과 연결; 첫 단원이면 \"\")",
 "sum": "개념 정리 4~6문장. '왜 그런지'까지. 학년 수준 말투(초등 해요체).",
 "pr": [{"h":"원리 이름","b":"원리 설명 1~3문장, 공식은 쉬운 말과 함께"} x 2~3],
 "items": [ITEM x 10],
 "mc": [MC x 8]
}
ITEM = {"t":"용어(2~12자)","d":"정의·원리 한 문장(60자 이내)","y":null,"yl":"","k":"개념|원리|법칙|현상|실험|구조|단위|관측","ex":"생활 속 예나 실험 장면 한 문장"}
 - 한 단원 안 10개 용어·정의는 서로 겹치지 않고, 정의가 다른 용어에도 맞으면 안 된다(설명 보고 용어 고르기/OX 퀴즈에 쓰임).
 - 정의 안에 그 용어 자체를 쓰지 않는다.
 - 앞 단원에 나온 용어를 다시 써야 하면 새 단원에서는 더 깊은 측면을 정의한다(같은 정의 반복 금지).
MC = {"q":"질문","p":"자료·상황(없으면 \"\")","c":[4개, 서로 다름],"a":0~3,"e":"해설 1~2문장(정답 이유+흔한 오답)","lv":1|2|3}
 - 단원마다 lv1 쉬움 3 · lv2 보통 3 · lv3 어려움 2. 어려움은 실험·자료 해석, 간단한 계산, 두 개념 연결.
 - 정답 위치 a를 골고루. 계산은 반드시 직접 검산. 정답은 정확히 하나.
 - 밑줄은 p 안에서 [[말]].

## 품질
- 과학적 정확성 최우선. 한국 교과서 표준 용어. 단위는 SI(한국어 이름 병기 가능).
- 초등: 해요체, 쉬운 낱말. 중등·고등: 합니다/한다체 가능.
- 저작권 있는 교과서 문장 베끼지 말 것. 직접 작성.
- 같은 폴더의 기존 파일(../phy.json, ../chem.json, ../bio.json, ../earth.json — 검토 완료본)에 같은 주제가 있으면 내용을 재사용·확장해도 좋다.
- 작업 파일은 /tmp/claude-0/-home-claude/c7c64cc0-5c20-56de-8853-021269d6df9c/scratchpad/data/sci/v2/work_<본인 파일 이름>/ 아래에만. **scratchpad/build/ 폴더에는 절대 아무것도 만들거나 고치지 말 것.** 다른 작성자의 파일도 건드리지 말 것.
- 다 쓰면 python으로 검증: JSON 로드, 단원 수=배정 수, 단원마다 items 10·mc 8·mc lv 3/3/2, 선택지 4개 서로 다름, a∈0..3, 정의에 용어 없음, 단원 안 용어·정의 중복 없음. 통과할 때까지 고친다.
- 마지막으로 스스로 한 번 더 사실 검토(정답·계산·용어)를 하고 고친다.

보고: 단원 목록, 개수, 확신이 없는 점만 짧게.

## 보충 단원(add_*.json) 규칙
- 형식: {"units":[UNIT+{"after":"이 단원 바로 뒤에 넣을 기존 단원 title (같은 lv 파일 안). 맨 앞이면 \"^\""}]}
- 반드시 같은 영역의 기존 파일(v2/<영역>_0/1/2.json)을 먼저 읽고: 이미 있는 용어 정의를 그대로 반복하지 말고, pre로 앞 단원과 연결하고, 뒤 단원과도 자연스럽게 이어지게.
- 기존 파일은 절대 수정하지 말 것. 출력은 add_<영역>.json 하나만.
