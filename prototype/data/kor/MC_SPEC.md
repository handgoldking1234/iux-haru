# 국어 객관식(문제 은행형) 작성 규칙

출력 JSON: {"mc":[MCQ,...]}
MCQ = {
 "unit": 단원 제목(입력 파일의 title 그대로),
 "lv": 1|2|3   (1 쉬움 · 2 보통 · 3 어려움 — 단원마다 lv1 2문제, lv2 2문제, lv3 1문제)
 "q": 발문 (예: "다음 중 맞춤법이 바른 문장은?", "밑줄 친 말의 품사로 알맞은 것은?", "다음 속담과 뜻이 가장 비슷한 것은?")
 "p": 지문·보기 (필요할 때만, 한두 문장. 밑줄은 [[ ]]로 감싼다. 예: "동생이 [[예쁜]] 꽃을 샀다."), 없으면 ""
 "c": 선택지 정확히 4개 (짧게, 각 40자 이내)
 "a": 정답 번호 0~3 (정답 위치를 고르게 섞을 것)
 "e": 해설 1~2문장 (왜 정답인지, 오답이 왜 틀린지 핵심만)
}
원칙:
- 한국 학교 내신·학력평가·국가 시험에서 쓰는 문제 형식을 본떠 **새로 작성** (기출·문제집 문항을 그대로 옮기지 말 것).
- 정답은 반드시 하나. 다른 선택지는 분명히 틀려야 함(맞춤법 문제의 오답은 실제로 틀린 표기).
- 국립국어원 표준국어대사전·한글 맞춤법·학교 문법 기준. 학교급 눈높이 맞추기.
- 같은 단원의 기존 items(낱말·설명)와 겹쳐도 되지만 문제는 응용형으로(문장 속 적용, 사례 판단).
- 완성 후 python 검증: 파싱, 단원당 5문제, c 4개, a 0~3, 정답 위치 분포가 한쪽으로 쏠리지 않게. 마지막에 "done N"만 보고.
